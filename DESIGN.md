# Ecommerce Design System

## Design Direction

Build a premium modern ecommerce website inspired by:

- Apple
- Shopify premium themes
- Linear
- Stripe
- Vercel
- Raycast
- Minimal luxury ecommerce brands

The design should feel:

- modern
- premium
- minimal
- elegant
- spacious
- high-end
- smooth
- polished

Avoid:

- cluttered layouts
- generic ecommerce styling
- inconsistent spacing
- heavy gradients
- outdated UI patterns

---

Animations should feel:

- subtle
- smooth
- premium
- lightweight

Use:

- hover lift effects

- subtle floating effects
